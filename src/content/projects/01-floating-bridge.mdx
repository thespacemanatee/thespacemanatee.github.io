This project is my proudest one to date. Built with React Native, Node, Express and MongoDB, what started out as a pet project for my friends became a production ready, fully deployed web game. The game server is hosted on Digital Ocean, frontend on AWS Amplify, and game assets are served with AWS CloudFront CDN. This project pushed my systems and architecture design concepts to the limits.
